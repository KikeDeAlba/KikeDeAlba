## 🚀 Proyectos Destacados

### ✈️ API de Venta de Vuelos Internacionales
Desarrollo y soporte de un backend en **NestJS** para la comercialización de vuelos, integrando:
- NDC de aerolíneas como Iberia
- Flujos de pago con plataformas como Yuno y Doters
- Arquitectura desplegada en **AWS** mediante contenedores, Lambdas y EventBridge
- Monitoreo en Datadog

### 🔐 Sistemas de Autenticación SSO
Implementación y mantenimiento de flujos de autenticación y autorización para aplicaciones empresariales, priorizando:
- Seguridad
- Escalabilidad
- Mantenibilidad

### 🎁 Vivagift
Implementación de mecanismos de encriptación para gift cards, fortaleciendo la seguridad de datos sensibles de clientes en un sistema basado en **NestJS** y **Vue.js**.

### 🍽️ Focografico POS
Sistema de punto de venta para restaurantes, donde participé como **líder de equipo** y desarrollador backend:
- Backend con **FastAPI**
- Frontend móvil con **React Native** y Expo
- Despliegues en EC2 con Docker, Nginx y SSL
